# NNUE networks

Trained networks in the JNN1 file format the engine loads via UCI's
`EvalFile` option. All files here are architecture HalfKP → 256 → 1
(41,024 features per perspective, single hidden layer, single output)
matching `src/nnue_types.h`.

## default.jnn1 — v7 (bigger-corpus Stockfish-labeled)

Trained on a 104,854-position corpus generated by self-playing the
previous champion (v4 — see history below) over 2000 games with the
`noob_3moves.epd` opening book (150,932 openings for diversity), then
re-labeling every quiet position with locally-installed Stockfish 19
at search depth 10. Training ran 50 epochs with the Phase 2 loop:
AdamW (`weight_decay=1e-4`), linear-warmup → cosine-decay LR
(`peak=1e-3`, `warmup_frac=0.05`), gradient clipping at L2 norm 1.0,
batch size 2048. Final val_loss = 0.045.

**SPRT validation (`tc=5+0.05`, `noob_3moves.epd`):**

| vs | Games | Score | LLR | Elo |
|---|---|---|---|---|
| v4 (previous default) | 288 | **288-0-0** | -2.96 crosses H0 at [0, 5] | tuned ≈ **+900 Elo** stronger |
| classical eval (`UseNNUE=false`) | 294 | 1-293-0 | +2.95 crosses H1 at [0, 5] | classical ≈ **+987 Elo** stronger |

**What this means**

v7 is a massive improvement over the v4 self-bootstrap peak that was
previously shipped as `default.jnn1`. The 288-0 sweep covers both
colors evenly (144 wins as white, 144 as black). Material
understanding is dramatically better than v4 — K+Q vs K now evaluates
to 270 cp vs v4's 132 cp (still an under-estimate of a queen's actual
value, but 2× closer).

**v7 does NOT beat the engine's classical eval.** The classical mode
remains the engine's competitive setting; `UseNNUE=true` is for
experimentation and continuing-to-train rather than for stronger play.
Closing the ~1000-Elo gap to classical likely requires architectural
work (larger hidden layer, HalfKAv2 features, output buckets) rather
than more data at the current 256-unit size.

**Reproduction:**

```bash
# 1. Fetch an opening book (150k positions).
curl -L -o /tmp/noob_3moves.epd.zip \
    https://github.com/official-stockfish/books/raw/master/noob_3moves.epd.zip
unzip /tmp/noob_3moves.epd.zip -d /tmp

# 2. Self-play 2000 games with the previous NNUE loaded (~90 min).
scripts/gen_selfplay_data.py --games 2000 --movetime-ms 30 \
    --book /tmp/noob_3moves.epd --seed 200 \
    --engine-option UseNNUE=true \
    --engine-option EvalFile=nets/default.jnn1 \
    --output /tmp/selfplay_2000.txt

# 3. Re-label with Stockfish depth 10 (~27 min; needs
#    `brew install stockfish` or equivalent).
scripts/stockfish_label.py --input /tmp/selfplay_2000.txt \
    --output tests/data/sf_labeled_v2.txt --depth 10

# 4. Train 50 epochs with the Phase 2 loop (~25 min on CPU).
training/train.py --data tests/data/sf_labeled_v2.txt \
    --out /tmp/v7.jnn1 --epochs 50 --batch 2048 \
    --weight-decay 1e-4 --warmup-frac 0.05 --grad-clip 1.0 --seed 42

# 5. SPRT-validate (~22 min each).
scripts/sprt.py --baseline ./engine --tuned ./engine \
    --baseline-option UseNNUE=true \
    --baseline-option EvalFile=nets/<prior-default>.jnn1 \
    --tuned-option UseNNUE=true \
    --tuned-option EvalFile=/tmp/v7.jnn1 \
    --book /tmp/noob_3moves.epd --tc 5+0.05 --max-games 400
```

**Usage:** off by default. Enable per-run via UCI:

```
setoption name EvalFile value nets/default.jnn1
setoption name UseNNUE value true
```

Order matters — set `EvalFile` before `UseNNUE=true` to avoid a
transient `info string UseNNUE=true but no network loaded` warning.

## Historical: v1-v4 self-bootstrap chain (now superseded by v7)

Prior to v7 the shipped `default.jnn1` was the peak of a 4-round
self-bootstrap chain:

| Round | Trained on | vs prior generation | vs v1 baseline |
|-------|------------|---------------------|----------------|
| v1    | 500 self-play games (noob_3moves.epd, 50ms/move), WDL labels        | seed          | seed          |
| v2    | 200 games self-played by v1, score labels from v1 (depth 4)         | +67 Elo       | +67 Elo       |
| v3    | 200 games self-played by v2, score labels from v2 (depth 4)         | +108 Elo      | +89 Elo       |
| v4    | 200 games self-played by v3, score labels from v3 (depth 4)         | +54 Elo       | **+130 Elo**  |
| v5    | 200 games self-played by v4, score labels from v4 (depth 4)         | −51 Elo       | (regressed)   |

v5 regressed from v4 due to self-distillation collapse — compounded
label bias eventually overwhelmed the smoothing benefit. The v4 peak
was the shipped default from Sep 2026 until v7 landed in Oct 2026.
The key architectural change in v7 is **external teacher** (Stockfish
depth 10) instead of self-distillation, which breaks the ceiling the
chain hit at v4.
